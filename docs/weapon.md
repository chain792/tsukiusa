# 武器一覧

## レア度の見方
- **X4**: 下級（最も低いランク）
- **X3**: 中級
- **X2**: 上級
- **X1**: 最上級（各ティアで最も高いランク）

## 画像パスについて
各武器の画像は `src/assets/{レア度}.png` に配置されています。
例: L4 → `src/assets/L4.png`

## 銀色の銀河バズーカ（U3）詳細

2026-06-25 のアップデートで「ユニバースの力」システムとともに追加。
出典: [公式wiki](https://w.atwiki.jp/tsukiusa/pages/1493.html)

### 所持効果（レベルで変動）
| レベル | 効果 |
|---|---|
| Lv.0 | 攻撃力 436,490% / 与ダメージ増幅 25% |
| Lv.150 | 攻撃力 763,857.5% / 与ダメージ増幅 62.5% |

### 装着効果（レベルで変動）
| レベル | 効果 |
|---|---|
| Lv.0 | 攻撃力 7,194,825% / 攻撃速度 420% / 会心率 30% / 会心ダメージ 600% |
| Lv.150 | 攻撃力 17,987,060% / 攻撃速度 420% / 会心率 30% / 会心ダメージ 900% |

### ユニバースの力（段階解放）
| 段階 | 必要財貨 | 効果 |
|---|---|---|
| 力開放 | ユニバース【中級】武器 1個 | ボスへの最終ダメージ +80% / 一般モンスターへの最終ダメージ +80% |
| 1つ目の力 | ギャラクシー【中級】武器 2個 | 味方全体のダメージ(ユニバース) +20% / 最大レベル +10 |
| 2つ目の力 | ギャラクシー【上級】武器 1個 + ギャラクシー【中級】武器 1個 | 味方全体のダメージ(ユニバース) +30% / 最大レベル +15 |
| 3つ目の力 | ギャラクシー【最上級】武器 1個 + ギャラクシー【上級】武器 1個 | 味方全体のダメージ(ユニバース) +50% / 最大レベル +25 |

※ 1〜3つ目の力の前提条件として「銀色の銀河バズーカの力」を先に開放する必要があります。
