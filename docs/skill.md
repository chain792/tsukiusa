# スキル（リン）

出典: [公式wiki スキル（リン）](https://w.atwiki.jp/tsukiusa/pages/140.html)（2026-06-04 更新）

## データの持ち方

実データは `src/lib/skills/data.ts` にある（全 **73** スキル）。docs には重複させず、ここには**スキーマと出典**、および一覧表からは読み取れない仕様を残す。

```ts
interface Skill {
  id: string;              // 英語名から生成した slug
  ja: string; en: string;  // en は公式表記が未確認のため暫定訳
  tier: 'Rare' | 'Unique' | 'Epic' | 'Legend' | 'Star';
  element: 'Light' | 'Dark' | 'Fire' | 'Water';
  kinds: ('Attack' | 'Buff' | 'Debuff')[];   // 複合あり（例: デバフ型＋攻撃型）
  targets: (...)[];        // Self / Single / Multi / AreaEnemy / AreaFixed / AreaTracking / AreaSelf
  cooldown: number;        // 秒。最短は闇の種子 1s、ソウル・ドレイン 1.5s
  mpLv1: number;           // スキルLv.1 のMP消費量
  mpMax: number;           // スキルLv.110（MAX）のMP消費量
}
```

## スキルレベルの上限

| 区分 | 上限 |
|---|---|
| レア〜レジェンド（69件） | **Lv.110** |
| スター（4件） | **Lv.100** |

一覧ページ（140）のヘッダーは全等級とも「MAX (lv.110)」と書かれているが**誤り**。
個別ページを見るとスタースキルは `lv.1 / lv.100` の2点で記載されている。
`src/lib/skills/details.ts` の `maxLevel` が正。MP計算は `getEffectiveLevel()` で上限に丸めている。

## MP消費量のスケーリング（推定式・実測による裏取りは未実施）

wiki に載っているのは **Lv.1 と Lv.110 の2点だけ**。実プレイではスキルレベルが 300 まで普通に伸びるため、
サイトでは以下の推定式で外挿している（`src/lib/skills/utils.ts` の `getMpAtLevel()`）。

```
MP(Lv) = MP(Lv.1) × (1 + 0.01 × (Lv - 1))
```

= 毎レベル Lv.1 の値の1%ずつ加算。Lv.110 で ×2.09、Lv.300 で ×3.99。

### wiki の最大レベル値との照合（コードで検証済み）

MP消費が0でない71件について、`Math.round(mpLv1 × (1 + 0.01 × (maxLevel - 1)))` と wiki 値を突き合わせた結果:

| 結果 | 件数 | 内訳 |
|---|---|---|
| 完全一致 | **62** | — |
| 1 だけずれる | 7 | 計算値がちょうど `.5` になるケース。wiki は切り捨て側（例: 250×2.09 = 522.5 → wiki 522）<br>光の祝福 / ファイア・トルネード / メテオ / アイス・オーブ / 海神の槍 / 水の怒り / ポール・ディグニティ |
| 3〜4 ずれる | 2 | スプリングトラップ！（計算836 / wiki840）、オデッセイ（計算627 / wiki630）。wiki側の誤記の可能性 |

スター4件は上限 Lv.100 で**完全一致**。異なる最大レベルで同じ式が成立しているため、式の裏付けになっている。

丸めは `Math.floor` だと浮動小数点誤差で大きく崩れる（40/71）ため `Math.round` を使う。

> ゲーム内実測での確認は未実施。UIでも推定値である旨を明示している（`skillCatalog.levelNote`）。
> 実測値が判明したら `getMpAtLevel()` と本節を更新すること。

MP消費が 0 のスキル: **マナの祝福**（レア/水）、**サクリファイス**（エピック/闇）。

## MP効率（サイトで算出している指標）

`MP/秒 = MP(指定Lv) ÷ cooldown`。クールタイムごとに撃ち続けた場合の理論的なMP消費レート。
`src/lib/skills/utils.ts` の `getMpPerSecond()`。

これは wiki には無いサイト独自の指標。値が小さいほどMP効率が良い。

## スキルルーン（未実装・調査メモ）

個別スキルページ（例: [ライトニング・ストライク](https://w.atwiki.jp/tsukiusa/pages/20.html)）に記載あり。
**確率はスタースキルとそれ以外で異なる**（全73件を確認済み）。

| 等級 | レジェンド以下（69件） | スター（4件） |
|---|---|---|
| マジック | 40% | 39% |
| レア | 30% | 30% |
| ユニーク | 20% | 20% |
| エピック | 7% | 7% |
| レジェンド | 3% | 3% |
| スター | — | 1% |

- 等級内の各効果の登場確率は同一
- レジェンド以下: レジェンド効果は1つのみ登場する
- スター: レジェンド効果とスター効果は、どちらかが最大1つのみ登場する
- スキルルーンの等級（中級・上級）は、効果の登場確率とは関係ない
- **効果の内容はスキルごとに異なる**（ライトニング・ストライクはクールタイム減少、魅惑の審判はMP消費量減少＋固有効果）

効果の内容（ダメージ増加 / クールタイム減少 / MP消費量減少 の各段階）もスキルごとにページに載っている。
→ 期待値計算ツールを作れる余地があるが、中級/上級の差やオプション枠数が未確認。`docs/ideas.md` 参照。

## 詳細データ（`src/lib/skills/details.ts`）

全73件の個別ページから取得済み（2026-08-23）。

| フィールド | 内容 |
|---|---|
| `maxLevel` | 110（レジェンド以下）/ 100（スター） |
| `ownEffect` | 所持効果。`label` + 覚醒段階1〜8の `values` + `unit` |
| `inheritsFrom` | スタースキルが継承するレジェンドスキル3つ。他は null |
| `effectLv1` / `effectMax` | 発動効果のテキスト（ダメージ%を含む） |
| `awakening` | レジェンド以下は5覚醒のみ、スターは1/3/5覚醒 |

## 取得方法

個別ページは `curl` で取得できる（ブラウザ相当のヘッダーが必要）。ページIDは
`スキル（リン）`(140) の表内リンク（`#wikibody table a`）から順番に取れ、`src/lib/skills/data.ts` の並び順と一致する。
パース手順は `.claude/skills/tsukiusa-research/SKILL.md` を参照。
