# 新機能・新ページのアイデア

ステータス: `未着手` / `実装中` / `完了` / `却下`

## 優先度 高

### 1. 武器図鑑に攻撃力を表示 — `未着手`
現在の武器図鑑は「必要本数」だけ。@wiki には全等級の**攻撃力（Lv.0 / 最大Lv）**がある（`docs/weapon.md` 参照）。
- カードに攻撃力を追加、または「必要本数 / 攻撃力」の表示切替
- 「1本あたりの費用対効果（攻撃力 ÷ 必要L1本数）」を出すと合成の意思決定に直結する
- データはすでに `docs/weapon.md` にあるので `src/lib/weapons/` に載せるだけ

### 2. ユニバースの力 解放シミュレータ — `未着手`
銀色の銀河バズーカ（U3）の「力」解放に必要なギャラクシー武器を計算するページ。
| 段階 | 必要財貨 |
|---|---|
| 力開放 | ユニバース【中級】×1 |
| 1つ目 | ギャラクシー【中級】×2 |
| 2つ目 | ギャラクシー【上級】×1 + 【中級】×1 |
| 3つ目 | ギャラクシー【最上級】×1 + 【上級】×1 |

- 全段階を L1 換算すると合計何本かを出す
- 既存の `getRequiredBase()` がそのまま使える
- 「武器目標計算」に組み込む案もある

### 3. クーポンコード一覧ページ — `未着手`
パッチノート表紙に隠しコードが入る（例: `IFOUNDYOU05`）。Discord #クーポン と併せて一覧化。
- 有効/期限切れの区別、コピーボタン
- 検索流入が見込める（「月ウサギ クーポン」）
