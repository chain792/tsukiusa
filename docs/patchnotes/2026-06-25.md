## 追加コンテンツ
### 新規武器の追加 —【ユニバースの力】
**銀色の銀河バズーカ（ユニバース中級 / U3）** に関する「ユニバースの力」システムが追加。

| 区分 | 必要財貨 | 所持効果 |
|---|---|---|
| 銀色の銀河バズーカの力開放 | ユニバース【中級】武器 1個 | ボスへの最終ダメージ +80% / 一般モンスターへの最終ダメージ +80% |
| 1つ目の力 | ギャラクシー【中級】武器 2個 | 味方全体のダメージ(ユニバース) +20% / 銀色の銀河バズーカの最大レベル +10 |
| 2つ目の力 | ギャラクシー【上級】武器 1個 + ギャラクシー【中級】武器 1個 | 味方全体のダメージ(ユニバース) +30% / 最大レベル +15 |
| 3つ目の力 | ギャラクシー【最上級】武器 1個 + ギャラクシー【上級】武器 1個 | 味方全体のダメージ(ユニバース) +50% / 最大レベル +25 |

※ 1〜3つ目の力の前提条件として「銀色の銀河バズーカの力」を先に開放する必要がある

### 月の試験 新規シーズンの開幕
- 新シーズン開始、戦闘力に比例して試験の鏡の段階が再調整
- 前シーズンの 月の試験スキル / 月の試験能力値 / 月の試験の鍵 / 成長の鏡入場チケット がリセット
- 所持中の黎明の呼びかけ入場チケットは、新シーズン開始後の初回入場時に自動消費され報酬支給
- 月の試験の鍵で好きなタイミングに開放可能。開放後7日間「試験の鏡」「成長の鏡」に入場可能
- 開放しなかった場合、シーズン終了7日前に自動開放
- 月の試験強化スキルは【光の審判】と【メテオ】。スキルルーンと5覚醒効果は非適用だが基本性能は強化
  - 光の審判: 攻撃対象数、ダメージ増加
  - メテオ: ダメージ増加

### スキルバランスの調整
スタースキル【魅惑の審判】【ラヴァバレット】【アクアウェーブ】を調整。
- 魅惑の審判: 審判の刃3回突き刺し、それぞれ 4,500% → **6,000%** ダメージ（他の数値は詳細未読）

## イベント予告
### 月ウサPOP（ミニゲーム）
- 次々と登場するノーツをタイミングに合わせて処理するリズムミニゲーム
- 指定軌道を回る「判定ライン」が「ノーツ」に重なる瞬間に画面タップ。コンボ成功でSCORE獲得
- ノーツをクリアするほど判定ラインの移動速度が上昇
- 7月最初のアップデートまで開催

### 月ウサギサバイバル
- 押し寄せる敵を倒し、スキルを獲得して最高ポイントを目指すサバイバルイベント
- 最高ポイントで等級決定、毎日00:00基準で等級報酬支給。サーバー/グローバルランキングあり
- 月ウサギに別途の能力値とスキルレベルが適用され、未所持スキルも使用可能
- 今回はスタースキル「アクアウェーブ」「チェインライトニング」をサバイバルスキルとして獲得・使用可能

### 5周年記念イベント終了の事前案内
- 終了後も報酬交換できるよう進入ボタンは継続表示
- 表示期間中は「シェイカーオープン」「カクテル提出」「いっぱいガチャ」で残イベント財貨を消費可能
- 7月2回目アップデート時点で未使用のイベント財貨は一定量のルビーに変換
