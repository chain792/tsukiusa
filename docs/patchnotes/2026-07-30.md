# パッチノート 2026-07-30

## システム
### 仲間入れシステムのリニューアル
「守護者の道」に「チャプター突破 / 成長任務 / 仲間入れ」タブが整理され、惑星マップから仲間を選ぶ形式に。

登場する守護者:
- 天王星の守護者 ニア / 土星の守護者 ユナ / 海王星の守護者 シーラ / 金星の守護者 ミホ

【仲間入れ方法】
1. 指定のチャプター区間をクリア（仲間入れ回数を獲得）
2. 好きな仲間を選択
3. 仲間入れミッションをすべて完了
4. 仲間ストーリーをクリア
5. 仲間入れ完了

- リニューアルにより「ユナに会いに行こう！」「シーラに会いに行こう！」は終了。進行中の履歴がある場合、仲間入れミッションオープン時の進行分が反映

【追加の案内事項】
- 仲間入れ・ストーリークリア後、仲間入れストーリーをリプレイできる機能を追加
- ガイドクエスト292が「仲間入れをする」に変更
- 超越ストーリー入場条件が「ニア仲間入れ」→「仲間入れをする」に変更
- 仲間ストーリークリア後、仲間入れストーリー初回進入時に必要だった「仲間の証 × 20,000個」を削除

|---|---|---|

### 仲間入れパック
- 選択した仲間の仲間入れミッション進行画面で、その仲間の「ジャンプアップパック」を購入可能
- 購入するとその仲間の全仲間入れミッションを即達成＋報酬全獲得、仲間ストーリーへ即進行

### 仲間成長リニューアルおよびバランス調整
- 月ウサギの成長要素の一部が仲間にも適用されるよう仕様変更、仲間の能力値反映方式を改善
- アップデート後、成長状況に応じて戦闘力が変動する場合あり

【仲間適用効果リスト】月ウサギの成長要素のうち仲間にも適用されるもの:
- 武器スペシャル所持効果、魔法弾スペシャル所持効果、魔法弾50レベルボーナス効果、ペット装着効果、一部の次元の力効果、コンテンツ内の一部バフ効果など
- ※ 一部の効果およびバフは適用対象外

【仲間バランス調整】（数値はレベル1基準）
- ニア: 弱点発見 対象の被ダメージ 25% → **40%** / 士気高揚 自分と月ウサギの最終攻撃力32%増加 → **すべてのダメージ22%増加** / 剣術の極意 防御貫通力10% → **12%** / 天空の剣術（新規）通常攻撃時、対象の受ける全属性ダメージを3秒間2%増加
- ニア(7/31追記): 士気高揚(100レベルボーナス) 攻撃力増加量が追加で30%増加 → **すべてのダメージ増加量が追加で30%増加**
- シーラ: トゲの蔓 敵の被ダメージ 25% → **30%** / トゲの蔓(100レベルボーナス) さらに25% → **30%** / 捕食者の目 自分と月ウサギの最終攻撃力40% → **30%** / 乱暴な気勢 すべてのダメージ30% → **15%**
- ※ ミホ・ユナの調整も同パッチに含まれる（詳細は原文参照）
